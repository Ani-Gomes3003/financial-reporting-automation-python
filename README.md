# Financial Reporting Automation System (Python)

## Overview
Automated financial analytics pipeline that processes monthly operational Excel files and generates structured performance reports.

## Features
- Reads multiple Excel files automatically
- Combines monthly financial data
- Calculates financial KPIs:
  - Revenue per Hour
  - Revenue per Transaction
  - Error Percentage
  - Productivity metrics
- Generates department and monthly summary reports

## Tools Used
Python, pandas, openpyxl

## Input
input_files/
jan_2025.xlsx
feb_2025.xlsx
mar_2025.xlsx

## Output
output/financial_summary_report.xlsx

## How to Run
python automation.py
